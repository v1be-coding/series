# V1be Coding: the series

A build series where each app goes from spec to working, deployed app in one agent run. This repo holds what every episode shares.

| File | Holds |
| --- | --- |
| [`V1BE_CODING.md`](./V1BE_CODING.md) | What the series is, its rules, workflow and episode lineup |
| [`GLOSSARY.md`](./GLOSSARY.md) | The terms every episode uses |
| [`docs/adr/`](./docs/adr/) | The decisions behind the Foundation, and why they were made |
| [`CHANGELOG.md`](./CHANGELOG.md) | How the workflow changes as the series runs |

The infrastructure itself is in [`v1be-infra`](https://github.com/v1be-coding/v1be-infra).
